# 生图参数参考（按模型）

本文档按模型列出五家图像生成服务的生图参数，重点覆盖：

1. **size 尺寸参数**：按 `ratio 比例` + 该比例下的 `1K / 2K / 4K（或最大尺寸）` 两种分辨率的表格呈现；
2. **其它参数**：若为枚举类型，列出所有可选值。

适用模型：OpenAI（GPT Image 系列）、xAI（Grok Imagine）、Google（Nano Banana / Gemini）。

***

## 一、OpenAI（GPT Image 系列）

适用模型：`gpt-image-2`（快照 `gpt-image-2-2026-04-21`）、`gpt-image-1.5`、`gpt-image-1`、`gpt-image-1-mini`、`dall-e-3`。

### 1.1 size 尺寸参数

`gpt-image-1` / `gpt-image-1-mini` 仅支持固定标准尺寸：`1024x1024`、`1536x1024`、`1024x1536`、`auto`。

`gpt-image-2`（及快照）**支持任意** **`WIDTHxHEIGHT`** **自定义分辨率**，但必须同时满足四条硬性规则：

| 规则   | 限制                          |
| ---- | --------------------------- |
| 长边上限 | 最长边 ≤ 3840 px               |
| 像素总量 | 总像素在 655,360 ～ 8,294,400 之间 |
| 边长对齐 | 宽、高均须能被 16 整除               |
| 宽高比  | 长边/短边 ≤ 3:1                 |

下表为满足上述规则的常见比例推荐档位尺寸（非官方档位，官方仅公布 `1024x1024`、`1536x1024`、`1024x1536` 三个标准尺寸）：

| ratio 比例 | 1K          | 2K          | 4K / 最大尺寸               |
| -------- | ----------- | ----------- | ----------------------- |
| `1:1`    | `1024x1024` | `2048x2048` | `2880x2880`（最大，像素恰好达上限） |
| `4:3`    | `1024x768`  | `2048x1536` | `3312x2480`             |
| `3:2`    | `1536x1024` | `2304x1536` | `3504x2336`             |
| `16:9`   | `1280x720`  | `2560x1440` | `3840x2160`（4K，实验性）     |
| `9:16`   | `720x1280`  | `1440x2560` | `2160x3840`（4K，实验性）     |

> 分辨率高于 `2560x1440` 的输出目前为 **experimental（实验性）**。

### 1.2 其它参数（枚举值全列）

| 参数                   | 类型     | 可选值                                                                          | 说明                                       |
| -------------------- | ------ | ---------------------------------------------------------------------------- | ---------------------------------------- |
| `n`                  | int    | 1–10                                                                         | 生成图片数量，默认 1                              |
| `quality`            | string | `low` / `medium` / `high` / `auto`（GPT Image 系列）；`hd` / `standard`（DALL·E 3） | 图片质量                                     |
| `background`         | string | `transparent` / `opaque` / `auto`                                            | 背景透明度，仅 GPT Image 系列；透明需配 `png` / `webp` |
| `output_format`      | string | `png` / `jpeg` / `webp`                                                      | 输出格式，仅 GPT Image 系列                      |
| `output_compression` | int    | 0–100                                                                        | 压缩级别，配合 `webp` / `jpeg`，默认 100           |
| `moderation`         | string | `low` / `auto`                                                               | 内容审核严格度                                  |
| `partial_images`     | int    | 0–3                                                                          | 流式返回中间过程图数量，默认 0                         |
| `prompt`             | string | 最多 32000 字符                                                                  | 提示词                                      |

> `response_format`（`url` / `b64_json`）对 GPT Image 系列**无效**——该系列始终返回 `b64_json`。

***

## 二、xAI（Grok Imagine）

适用模型：`grok-imagine-image-quality`（推荐）、`grok-imagine-image`（`grok-imagine-image-pro` 已于 2026-05-15 弃用）。

### 2.1 size 尺寸参数

Grok 没有"像素尺寸"参数，由 `aspect_ratio`（比例）+ `resolution`（档位）组合控制，官方未公布各比例的具体像素值：

| ratio 比例            | 说明         |
| ------------------- | ---------- |
| `1:1`               | 社交、缩略图     |
| `16:9` / `9:16`     | 宽屏、移动端、故事  |
| `4:3` / `3:4`       | 演示文稿、竖版    |
| `3:2` / `2:3`       | 摄影         |
| `2:1` / `1:2`       | 横幅、页头      |
| `19.5:9` / `9:19.5` | 现代手机屏幕     |
| `20:9` / `9:20`     | 超宽屏        |
| `auto`              | 模型自动选择最优比例 |

- `resolution` 档位：`1k` / `2k`（注意小写 k）。单图编辑时输出比例默认跟随输入图。
- 优先级：`size`（若有）› `aspect_ratio` + `resolution` › `aspect_ratio` › `resolution`。

### 2.2 其它参数（枚举值全列）

| 参数                | 类型     | 可选值                                                                                                                      | 说明                                 |
| ----------------- | ------ | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------- |
| `model`           | string | `grok-imagine-image-quality` / `grok-imagine-image`                                                                      | 模型                                 |
| `prompt`          | string | —                                                                                                                        | 提示词（编辑时为编辑指令）                      |
| `n`               | int    | 1–10                                                                                                                     | 批量生成数量（`sample_batch()`），默认 1      |
| `aspect_ratio`    | string | `1:1` / `3:4` / `4:3` / `9:16` / `16:9` / `2:3` / `3:2` / `9:19.5` / `19.5:9` / `9:20` / `20:9` / `1:2` / `2:1` / `auto` | 宽高比，默认 `auto`                      |
| `resolution`      | string | `1k` / `2k`                                                                                                              | 分辨率档位                              |
| `response_format` | string | `url` / `b64_json`                                                                                                       | 输出格式，默认 `url`（临时链接需及时下载）           |
| `image`           | object | `{ url: string }` 或 `{ file_id: string }`                                                                                | 单图编辑输入（`/images/edits`）            |
| `images`          | array  | `[{ url }]` 或 `[{ file_id }]`，最多 5 张                                                                                     | 多图参考编辑；prompt 中用 `\<IMAGE_0\>` 等引用 |
| `user`            | string | —                                                                                                                        | 终端用户标识（滥用监测）                       |

## 三、Google（Nano Banana / Gemini）

适用模型：`gemini-3.1-flash-image`（Nano Banana 2）、`gemini-3-pro-image`（Nano Banana Pro）、`gemini-3.1-flash-lite-image`（Nano Banana 2 Lite，仅 1K）、`gemini-2.5-flash-image`（旧版）。

### 3.1 size 尺寸参数（官方档位表）

通过 `image_config.image_size`（档位）+ `image_config.aspect_ratio`（比例）控制。下表为官方公布的 Nano Banana Pro（`gemini-3-pro-image`）10 种比例的 1K / 2K / 4K 实际输出尺寸：

| ratio 比例 | 1K          | 2K          | 4K          |
| -------- | ----------- | ----------- | ----------- |
| `1:1`    | `1024x1024` | `2048x2048` | `4096x4096` |
| `2:3`    | `848x1264`  | `1696x2528` | `3392x5056` |
| `3:2`    | `1264x848`  | `2528x1696` | `5056x3392` |
| `3:4`    | `896x1200`  | `1792x2400` | `3584x4800` |
| `4:3`    | `1200x896`  | `2400x1792` | `4800x3584` |
| `4:5`    | `928x1152`  | `1856x2304` | `3712x4608` |
| `5:4`    | `1152x928`  | `2304x1856` | `4608x3712` |
| `9:16`   | `768x1376`  | `1536x2752` | `3072x5504` |
| `16:9`   | `1376x768`  | `2752x1536` | `5504x3072` |
| `21:9`   | `1584x672`  | `3168x1344` | `6336x2688` |

`gemini-3.1-flash-image`（Nano Banana 2）额外支持极端比例与 0.5K 档：

| ratio 比例 | 0.5K       | 1K         | 2K          | 4K           |
| -------- | ---------- | ---------- | ----------- | ------------ |
| `1:4`    | `256x1024` | `512x2048` | `1024x4096` | `2048x8192`  |
| `4:1`    | `1024x256` | `2048x512` | `4096x1024` | `8192x2048`  |
| `1:8`    | `192x1536` | `384x3072` | `768x6144`  | `1536x12288` |
| `8:1`    | `1536x192` | `3072x384` | `6144x768`  | `12288x1536` |

### 3.2 其它参数（枚举值全列）

| 参数                          | 类型     | 可选值                                                                                                                          | 说明                     |
| --------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `image_config.image_size`   | string | `0.5K`（仅 3.1 Flash）/ `1K` / `2K` / `4K`                                                                                      | 分辨率档位，**必须大写 K**；默认 1K |
| `image_config.aspect_ratio` | string | `1:1` / `2:3` / `3:2` / `3:4` / `4:3` / `4:5` / `5:4` / `9:16` / `16:9` / `21:9`；3.1 Flash 另支持 `1:4` / `4:1` / `1:8` / `8:1` | 宽高比，默认 1:1（或跟随输入图）     |
| `model`                     | string | `gemini-3.1-flash-image` / `gemini-3-pro-image` / `gemini-3.1-flash-lite-image` / `gemini-2.5-flash-image`                   | 模型                     |
| `input`                     | array  | `[{ "type": "text" }]`、`[{ "type": "image" }]`                                                                               | 输入（文本 / 图片），最多 14 张参考图 |
| `tools`                     | array  | `[{ "type": "google_search" }]` 等                                                                                            | 工具（搜索接地等）              |
| `previous_interaction_id`   | string | —                                                                                                                            | 多轮修改时引用上轮交互            |

## 附：各模型 size 参数速查

| 模型                       | 尺寸控制方式                               | 是否有官方 1K/2K/4K 档位表   |
| ------------------------ | ------------------------------------ | -------------------- |
| OpenAI `gpt-image-2`     | 任意 `WxH`（需满足 4 条硬性规则）                | ❌ 官方仅 3 个标准尺寸，上表为推荐值 |
| xAI `grok-imagine-image` | `aspect_ratio` + `resolution`（1k/2k） | ❌ 未公布各比例像素值          |
| Google Nano Banana       | `image_size` 档位 + `aspect_ratio` 比例  | ✅ 官方完整档位表（见第三章）      |

## 四、三家 API 生图表单参数横向对比

下表以"生图表单字段"为行、三家 API 为列，标注各字段在每家 API 下的支持情况、必填性与取值。

### 4.1 核心必填字段

| 表单字段         | OpenAI `gpt-image-2`                                          | Grok `grok-imagine-image`                                          | Nano Banana（Gemini）                                                                      |
| ------------ | ------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 模型选择 `model` | 必填，5 选 1（`gpt-image-2` / `1.5` / `1` / `1-mini` / `dall-e-3`） | 必填，`grok-imagine-image-quality` / `grok-imagine-image`（`-pro` 已弃用） | 必填，4 选 1（`3.1-flash-image` / `3-pro-image` / `3.1-flash-lite-image` / `2.5-flash-image`） |
| 提示词 `prompt` | 必填，最长 **32000** 字符                                            | 必填，无明确上限                                                           | 必填                                                                                       |

### 4.2 尺寸参数

| 表单字段     | OpenAI                           | Grok                                                    | Nano Banana                                                       |
| -------- | -------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------- |
| 尺寸控件形式   | 比例下拉 + 档位/自定义 `WxH`（需满足 4 条硬性规则） | 比例下拉 `aspect_ratio`（14 个枚举）+ `resolution` 下拉（`1k`/`2k`） | 比例下拉 `aspect_ratio`（10 或 14 个枚举）+ 档位下拉 `image_size`（`0.5K`\~`4K`） |
| 尺寸必填性    | 可选（不传默认标准）                       | 可选（默认 `auto`）                                           | 可选（默认 1:1 / 1K）                                                   |
| 是否有官方档位表 | ❌ 需客户端校验                         | ❌                                                       | ✅                                                                 |
| 极端比例     | 比例 ≤ 3:1（**不允许** 21:9）           | ✅ 支持 19.5:9、20:9、1:2、2:1                                | ✅ 支持 21:9，3.1 Flash 另支持 1:4、8:1                                   |

### 4.3 通用可选字段

| 表单字段                   | OpenAI                          | Grok                              | Nano Banana          |
| ---------------------- | ------------------------------- | --------------------------------- | -------------------- |
| 图片数量 `n`               | ✅ 1–10                          | ✅ 1–10                            | ❌ 不支持                |
| 质量 `quality`           | ✅ `low`/`medium`/`high`/`auto`  | ❌（用 `resolution` 控制）              | ❌（用 `image_size` 控制） |
| 输出格式 `output_format`   | ✅ `png`/`jpeg`/`webp`           | ❌                                 | ❌                    |
| 背景 `background`        | ✅ `transparent`/`opaque`/`auto` | ❌                                 | ❌                    |
| 输出格式 `response_format` | ❌ 恒为 base64（参数无效）               | ✅ `url`/`b64_json`                | ❌ 恒为 base64          |
| 图生图输入                  | `/images/edits` 或 Responses API | `/images/edits`（`image`/`images`） | `input` 中传图片（base64） |
| 参考图数量上限                | 最多 16 张（<50MB）                  | 最多 5 张                            | 最多 14 张              |

### 4.4 各家专属参数

| 专属参数                               | OpenAI           | Grok    | Nano Banana |
| ---------------------------------- | ---------------- | ------- | ----------- |
| `moderation`（`low`/`auto`）         | ✅                | ❌       | ❌           |
| `partial_images`（0–3）              | ✅                | ❌       | ❌           |
| `output_compression`（0–100）        | ✅                | ❌       | ❌           |
| `tools`（google\_search 接地）         | ❌                | ❌       | ✅           |
| `previous_interaction_id`（多轮）      | ✅（Responses API） | ✅（链式调用） | ✅           |
| 水印                                 | 无                | 无       | SynthID（固定） |

### 4.5 调用模式与输出

| 维度     | OpenAI        | Grok            | Nano Banana |
| ------ | ------------- | --------------- | ----------- |
| 调用模式   | 同步            | 同步              | 同步          |
| 输出形式   | base64（无 URL） | 临时 URL 或 base64 | base64      |
| 单次生成数量 | 多张（`n`）       | 多张（`n`）         | 单张          |

### 4.6 表单设计结论

- **通用必填字段**（3 家一致）：`model` + `prompt`，是表单的固定部分。
- **尺寸控件需按 API 拆分**：OpenAI 用「自定义 WxH」输入；Grok / Gemini 用「比例下拉 + 档位下拉」。建议封装为一个"比例 → 各档位尺寸"的联动组件。
- **可选字段按 API 条件渲染**：`n`、`quality`、`background`、`output_format`、`moderation` 等仅 OpenAI 显示。
- **输出处理差异**：OpenAI / Gemini 恒返回 base64，直接收图；Grok 可选手 URL 或 base64（URL 有有效期需及时下载）。
- **图生图**：三家均支持，但输入位置与格式各不相同（`/edits`、`image`/`images`、`input`），表单的图片上传控件需按 API 映射到对应字段。
