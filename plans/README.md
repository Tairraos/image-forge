# plans/ — 轻量计划记录

这个目录用于保存进行中或稍后要接手的复杂任务计划。目的只是让另一个 Agent 能快速接手，不建立正式的项目管理体系。

## 用法

- 每个计划一个 Markdown 文件，命名用 kebab-case，例如 `plans/refactor-queue.md`。
- 计划文件至少包含：目标、当前状态、关键决策、待办、未解决问题。
- 任务完成后，把文件内容并入 `docs/` 或直接删除，避免残留过期计划。

## 模板

```markdown
# 标题

## 目标
一句话说明要达成什么。

## 当前状态
进行中 / 已暂停 / 已完成。

## 关键决策
- 决策 1 及原因

## 待办
- [ ] 事项 1

## 未解决问题
- 问题 1
```

## 说明

- 简单任务不需要计划文件，直接在对话里完成。
- 计划文件是给「换一个 Agent 接手」用的，不是给人类看的进度汇报。
